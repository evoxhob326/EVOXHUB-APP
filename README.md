# EVOXHUB Business Management

واجهة عربية RTL لإدارة أقسام EVOXHUB وREVE، ومتابعة الاستفسارات والمشاريع والمهام والموظفين والمحاسبة.

## تشغيل المعاينة

```powershell
npx --yes serve -l 4173 .
```

ثم افتح `http://127.0.0.1:4173/`. تسجيل الدخول ما زال يمر عبر Supabase كما في التطبيق الأصلي. صفحة طلب الخدمة العامة موجودة في `request.html`.

## بنية المشروع

- `index.html`: نقطة الدخول ومساحة التطبيق.
- `css/`: تنسيقات الواجهة القديمة والجديدة، مع قواعد للأجهزة الصغيرة.
- `js/modules/`: ميزات EVOXHUB الحالية، بما فيها النمر وعروض الأسعار والمهام.
- `js/v6/`: غرفة العمليات، الأقسام، الاستفسارات، الطلبات الواردة، الموظفون، المحاسبة، الكتالوج، والدليل.
- `data/services.json`: 58 خدمة أولية (39 EVOXHUB تشمل EVOX Go و9 REVE و10 CC142)، مع قائمة أسعار CC142 حسب فئة السيارة والإضافات.
- `supabase/migrations/`: مخطط الجداول والسياسات وطلب الموقع العام.
- `scripts/`: أدوات اختيارية للتعبئة ونقل سجلات المحاسبة القديمة.

## النشر والبيانات

تعليمات إعداد قاعدة اختبار ومراجعة النشر في [docs/DEPLOY.md](docs/DEPLOY.md). ترحيل SQL وعمليات تعبئة/نقل البيانات لا تُشغّل تلقائيًا. لا تضع `service_role` أو كلمات المرور أو رموز WhatsApp داخل المستودع.

## الاستخدام

اقرأ [دليل الاستخدام المختصر](docs/USER_GUIDE.md) قبل تسجيل بيانات حقيقية. الروابط الحالية تفتح رسالة واتساب جاهزة يدويًا؛ لا يوجد إرسال WhatsApp تلقائي.
